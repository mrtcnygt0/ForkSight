## Long description

ForkSight is an unofficial Chess.com training companion designed for post-game improvement.

It helps players review games, practice puzzles, and track progress with account-based coaching tools. The extension focuses on learning workflows, not automation.

What you can do with ForkSight:
- Practice puzzle and quiz-style training flows
- Use post-game coach review to understand mistakes and alternatives
- Track profile-based progress and performance trends
- Access optional Premium features for higher usage limits

Key points:
- Built for Chess.com training workflows
- Works through your ForkSight account on https://forksight.net
- Privacy policy available at https://forksight.net/privacy
- Not affiliated with, endorsed by, or sponsored by Chess.com

## Permission justifications (Privacy practices tab)

`storage`
Used to store user session data, language preference, and local extension settings required for account-based training features.

`notifications`
Used to show user-facing product notifications related to training/account activity.

`alarms`
Used to schedule periodic background checks for extension notifications.

`host permission: https://forksight.net/*`
Required to authenticate users and fetch account-based training data from the ForkSight backend.

## Single-purpose statement

This extension helps Chess.com users improve via post-game coaching, puzzle practice, and progress tracking.

## Remote code statement

All executable code is packaged in the extension. The extension does not download or execute remote JavaScript.
