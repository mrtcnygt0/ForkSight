# ForkSight Chrome Extension (Chess.com)

ForkSight is an unofficial Chess.com training and coaching extension.

## What it does

- Adds training-focused overlays and UI modules on Chess.com pages
- Supports puzzle and post-game coaching flows
- Uses account-based features through `https://forksight.net/*`

## Install locally

1. Open `chrome://extensions/`
2. Enable Developer mode
3. Click Load unpacked
4. Select this `extension` folder

## Permissions used

- `storage`: user session and local extension preferences
- `alarms`: periodic background checks
- `notifications`: user-facing extension notifications
- `host_permissions`: `https://forksight.net/*`
