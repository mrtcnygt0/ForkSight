Sık sorulanlar

Premium ne kadar sürede aktif olur?
GitHub hesabını bağladıysan, sponsorluğun bize ulaştığı anda (genelde saniyeler içinde) otomatik aktive olur. Önce sponsor olup sonra hesabını bağlarsan, bağladığın anda devreye girer.
GitHub hesabımı neden bağlamam gerekiyor?
GitHub bize yalnızca sponsorun GitHub kullanıcı adını bildirir. Doğru ForkSight hesabına premium tanımlayabilmemiz için bu iki hesabı eşlememiz gerekir.
Aboneliğimi iptal edersem ne olur?
Aylık sponsorluğu istediğin an GitHub üzerinden iptal edebilirsin. Mevcut fatura dönemin sonuna kadar premium açık kalır, sonra otomatik olarak Free'ye döner.
Kart bilgilerim güvende mi?
Evet. Tüm ödeme GitHub Sponsors altyapısında işlenir; ForkSight kart ya da ödeme bilgisi görmez, saklamaz.
Premium ne kazandırıyor?
Gold: günde 25 oyun analizi ve 30 ipucu, 5.000 karakter/gün sesli koç, derinlik 18 motor. Diamond: sınırsız analiz ve ipucu, 20.000 karakter/gün sesli koç, sınırsız detaylı koç incelemesi ve derinlik 25 motor gücü. İkisinde de açık kaynak projeyi yaşatırsın.
