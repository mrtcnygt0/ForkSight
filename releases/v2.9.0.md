# ForkSight v2.9.0

## Highlights

- Chrome Web Store hardening pass for compliance and review readiness
- Product positioning updated to Chess.com training and coaching
- Public privacy policy page added and deployed
- Packaging workflow updated for stable CWS ZIP generation

## Extension changes

- Removed legacy injected script path (`inject.js`)
- Simplified content integration to an auth-focused bridge
- Narrowed host permissions to `https://forksight.net/*`
- Removed API base override controls from popup and background handlers
- Updated extension naming/description for store-safe messaging

## Website and policy updates

- Reworked landing page messaging around post-game learning and coaching
- Added premium and privacy navigation paths in public pages
- Added `/privacy` route and policy page for store compliance
