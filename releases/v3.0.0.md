# ForkSight v3.0.0

Your personal chess coach on Chess.com — redesigned.

## Highlights

- Full UI refresh: Home, Profile, Coach, Training, My Games, Arena
- Secure Chess.com linking with a personal verification code (`FS-XXXXXX`)
- Onboarding + live sync progress for new accounts
- Improved puzzle feedback and hint flow
- Website refresh at https://forksight.net

## Install

- Chrome Web Store: https://chromewebstore.google.com/detail/forksight-%E2%80%94-chess-trainin/nbeldcglpjbmlklbakipohnjcpjmcikd
- Local / unpacked: load the `extension/` folder in `chrome://extensions`
