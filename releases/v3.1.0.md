# ForkSight v3.1.0

Multi-coach voices, personalities, and a “coming soon” Şero tease.

## Highlights

- Per-coach ElevenLabs voices (Tilki, Victoria, Boris, Kai, Lena) with separate TTS cache
- Personality-based analysis narration + quiz lines (TR/EN)
- Floating mini avatar follows selected coach (emotion sprites)
- Landing hero coach carousel with voice preview
- **Şero** street-cat coach preview — darkened “Coming soon / Cooking…” teaser (site + extension)
- Review summary CTA: Start Review above the “What happened?” block

## Install

- Chrome Web Store: upload `forksight-chesscom-v3.1.0.zip` (extension package)
- Unpacked: load the `extension/` folder in `chrome://extensions`
