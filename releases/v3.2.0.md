# ForkSight v3.2.0

Coach Play polish, Şero goes live, richer in-game commentary.

## Highlights

- **Koçunla Oyna** — game-over modal keeps the board visible; Retry + Exit (back to MY COACH)
- **Coach play commentary** — per-coach, position-aware lines (no SAN/move notation in TTS)
- **Şero** — fully selectable PRO coach with voice (ElevenLabs)
- **MY COACH** — recent training matches list with one-tap analysis
- Premium coach CTA hidden on coach tab for Diamond users

## Install

- Chrome Web Store: upload `forksight-chesscom-v3.2.0.zip`
- Unpacked: load the `extension/` folder in `chrome://extensions`
