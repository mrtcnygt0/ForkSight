# ForkSight v3.3.0

Learn path expansion, smarter coach insights, draggable panel, and reliable coach-game analysis.

## Highlights

- **Koçla Öğren** — Section 2 capture lessons (rook, bishop, queen, pawn, knight, master, check) with validated FENs and Chess.com-style map UI
- **Koçunla Oyna history** — training matches persist on the server across extension reloads
- **Coach game analysis** — PGN parser handles ambiguous SAN; `[ForkSightUCI]` header + direct UCI review from MY COACH
- **Dynamic coach insights** — home card builds sentences from puzzle accuracy, weakness report, and recent win rate (no more static +8%)
- **Draggable panel** — drag from header or sidebar brand; position saved in `chrome.storage`
- **Coach page i18n** — full Turkish translations for coach picker, skills, and CTAs

## Install

- Chrome Web Store: upload `forksight-chesscom-v3.3.0.zip`
- Unpacked: load the `extension/` folder in `chrome://extensions`
