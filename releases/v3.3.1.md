# ForkSight v3.3.1

Fix PGN analysis failing after castling (e.g. `Kb1` after `O-O-O`).

## Highlights

- **PGN castling SAN** — `O-O` / `O-O-O` now return a one-element UCI array instead of a bare string. The old string return made the resolver iterate characters (`e`,`1`,`c`,`1`), soft-skip empty squares, desync the board, and throw later on normal moves like `Kb1`.
- **Safer PGN apply** — empty from-square during SAN resolution throws instead of silently flipping the side to move.

## Install

- Chrome Web Store: upload `forksight-chesscom-v3.3.1.zip`
- Unpacked: load the `extension/` folder in `chrome://extensions`
